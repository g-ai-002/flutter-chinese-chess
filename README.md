# 中国象棋 🀄

基于 Flutter + Flame 的中国象棋，支持 Android、Windows 与 Web。规则严谨、界面克制，内置三档 AI、可选棋钟、八道残局、开局提示、走子提示、棋谱复盘与三套棋盘皮肤。

## 功能

- 🧠 完整规则：马腿、象眼、炮架、九宫、过河兵、将帅照面、将军/绝杀/困毙
- 🔁 裁定完善：六十回合无吃子判和、三次重复局面判和、长将判负
- 🤖 人机对战：入门 / 普通 / 高手三档（默认高手），本地 Alpha-Beta + 静态搜索，可选执红或执黑，三端搜索深度与时限一致
- 💡 走子提示：人机对战中一键请求建议着法，棋盘加粗金色箭头标注，6 秒后自动收起
- 🧩 搜索增强：迭代加深 + 置换表 + 杀手着法与历史启发，同等时间下多算一到两层，状态条展示 AI 层数与用时
- ⏱️ 限时对局：可选 5 / 10 / 20 分钟棋钟，超时判负，AI 思考同样计入本方用时
- 👥 双人同屏对弈，适合面对面手谈
- 🏁 残局挑战：八道杀法练习，从一步杀到三步杀，限步取胜并记录最佳步数
- 🧭 开局提示：内置常见开局库，实时显示开局名称与推荐着法，可随时关闭
- ♻️ 复盘回放：终局后逐手回看，支持自动播放、滑杆跳转与点击棋谱定位
- 🗂️ 棋谱库：自动保留最近 20 局对局回放，可随时打开、删除或清空
- 💾 棋谱导出导入：中文记谱一键复制或存为文本，支持粘贴导入与从导出目录选文件复盘
- 📜 中文棋谱：炮二平五、马8进7，实时记录并可随时查看
- ↩️ 悔棋、重开、认输，落子后自动切换行棋方
- 🎨 三套棋盘皮肤：檀木、青玉、墨韵，对局页、复盘页与首页缩略图同步
- 🔔 落子音效与震动反馈：运行时合成四级音效（落子 / 吃子 / 将军 / 终局），三端一致，可分别关闭
- 🎵 背景音乐：运行时合成五声音阶循环，可独立关闭，应用进入后台自动暂停
- ✨ Flame 木纹棋盘、红黑棋面分色、落子残影与落点涟漪，吃子时碎成粉末，棋盘与棋子分层缓存
- 🈶 Web 字体：使用 soup_fonts 思源黑体，仓库不存放字体文件，「卒」等字形完整
- 🎯 选中高亮、合法落点提示（可在设置中关闭）
- 📱 响应式布局：手机 / 折叠屏 / 平板 / Windows 窗口自适应，折叠屏展开时首页入口两列排布
- 🌓 深色模式、简体中文、Windows 优先使用 Microsoft YaHei UI
- 🧾 日志按天写入用户目录，设置页可直接查看最近日志

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release，运行 `main` 则产出预览产物。音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。
本地无需安装 Android SDK 等大型工具链。

## 日志位置

- Windows：`文档/FlutterChineseChess/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterChineseChess/logs/`
- Web：仅保留内存日志，可在设置页查看

导出的棋谱保存在 `<文档>/FlutterChineseChess/records/`，导入时可粘贴棋谱文本，或在导入弹窗中直接选取该目录下已导出的文件（Web 端使用剪贴板复制与粘贴）。

## 目录结构

```
lib/
├── game/       规则引擎、搜索、棋谱记法、开局库、棋谱编解码、复盘、残局关卡
├── flame/      Flame 棋盘组件与游戏入口
├── pages/      首页、对局页、残局页、棋谱库、复盘页、设置页及通用组件
├── services/   日志、偏好存储、棋谱库、文件系统
├── providers/  设置与进度状态
├── models/     对局模型与棋谱条目
├── theme/      配色主题与棋盘皮肤
└── utils/      常量、格式化、窗口初始化
```
